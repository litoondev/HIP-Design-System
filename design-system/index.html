Color accessibility — WCAG 2.1 Guidelines

Prioritize accessibility in UI color choices. Many ignore standards, making products hard for visually impaired users. Google penalizes low-contrast text, so ensure designs work for all, including older adults and color blind users. Focus on legibility with adequate contrast. See WCAG 2.1 for guidelines.

How much contrast do you need?
Use a 4.5:1 contrast ratio (WCAG AA) for essential UI elements like text and buttons to accommodate users with 20/40 vision loss.

Responsive Spacing & Layout Rules

Measured directly from the Home Page frames in the Figma source file (Desktop 1440px, Tablet 768px, Mobile 320px). This table is the mandatory spacing checklist for any new page or section built in this design system — every layout must hit these gaps at every breakpoint to stay visually consistent with the rest of the site.

Spacing rule Desktop (1440px) Tablet (768px) Mobile (320px)
Section-to-section gap 240px (120+120 padding) 120px (60+60 padding) 80px (40+40 padding)
Container left/right padding 100px 40px 20px
Section top/bottom padding 120px 60px 40px
Heading → paragraph gap 24px 20px 16px
Heading → heading gap (eyebrow → H2) 8px 6px 4px
Inner grid/card gap 40px (row & col) 30px (row & col) 20px (stacked, row only)
Paragraph-to-paragraph spacing 16px 16px 16px

How these were measured

Values were pulled from the three real Home Page frames in the Figma file — Home Page 1440px, Home - 768px, and Home - 320px — cross-checked across the Highlights grid, CTA, Our 5-Star Care, Locations, and Footer sections, which all share the same padding rhythm at each breakpoint.

Section-to-section gap is not an explicit margin — sections stack directly (0px between them) and the visual gap is produced by the bottom padding of the section above plus the top padding of the section below. Use the section top/bottom padding row when spacing out a new section, and it will automatically produce the correct combined gap.

Paragraph-to-paragraph spacing comes from the Body1 text style's built-in paragraph-spacing token (16px) and does not change across breakpoints.
